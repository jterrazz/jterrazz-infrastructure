# ADR-NNN: Title

**Status:** Accepted
**Date:** YYYY-MM-DD

An agent leaves the status `Proposed`; only the owner writes `Accepted`.

A retroactive record carries one honest line here: written YYYY-MM-DD from
the evidence it was reconstructed from. A record written at decision time
carries nothing.

The Decision states what holds today. When the tree changes it, edit the
Decision in place and add one line here, `Revised YYYY-MM-DD: <what changed>`;
git keeps the old wording. A decision reversed outright is a new record, and
this one's status becomes `Superseded by ADR-NNN`.
